# Sistema visual Nident

La plantilla `site/` es la autoridad visual, por instrucción del usuario.

- Violeta `#7258b6`, texto oscuro `#30283f`, superficies blancas y lavanda.
- Inter para lectura e interfaz, Plus Jakarta Sans para títulos. Se conservan las fuentes existentes aunque el detector las considere frecuentes.
- Usar imágenes odontológicas y logo existentes; contenido demo identificado.
- Web pública: preservar composición editorial, carruseles y movimiento accesible.
- Administración, modo Operate: formularios etiquetados, jerarquía compacta, biblioteca de plantillas, pieza central e inspector de bloques.
- Administración: barra lateral blanca con grupos de módulos, espacio de trabajo gris claro, acentos violeta, iconos SVG y formularios de operación. En móvil, navegación desplegable con fondo superpuesto y paneles apilados. Foco visible y ninguna tarea dependiente de arrastrar.
- Variables de correo escapadas como texto; vista final en iframe sandbox. Sin HTML ni scripts libres.
